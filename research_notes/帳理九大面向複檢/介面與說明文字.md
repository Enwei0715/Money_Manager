## 二、元件一致性：單選、標題、分隔線、按鈕、顏色、點擊波紋

### Takeaway
同一個畫面內仍會並排出現兩到四種選擇元件，按鈕的形狀與危險色也沒有統一。另外，全 App 預設保留 Material 點擊波紋，與使用者「不要波紋」的偏好相反。

### Cited Findings
- 〔圖〕`03_txns_analysis.png`：交易 → 分析，上排是外框 FilterChip 單選「每月／每季／每年」，下排緊接著是灰底 SubTabs「總覽／變化／習慣」。兩個上下相鄰的單選控制長得不一樣。〔碼〕`ui/screens/ReviewScreen.kt:122` 使用 FilterChip。
- 〔圖〕`18_notif_log.png`：通知記帳頁 SubTabs「紀錄／來源 App／進階」下面，又是一排 FilterChip 當單選「全部／已記帳／待確認／略過／無法辨識」。
- 〔圖〕`20_stock_2330.png`：個股頁一個畫面內有 SubTabs（走勢／分析／資訊）、SubTabs（60 分／日 K／週 K／月 K）、紅字文字列（區間：1 個月…自訂）、彩色可刪除膠囊（5 日 ✕…）、綠色與紅色訊號標籤、開關，以及底部膠囊按鈕，共七種互動元件。
- 〔圖〕`04_stats.png`：統計頁又是另一套：TabRow（收入／支出）加上外框下拉「每月 ▾」。
- 按鈕形狀不一致：〔圖〕`16_txn_linepay_60.png`、`17_txn_kyoto_85.png` 的「儲存／確認入帳／刪除／複製」是小圓角矩形；`20_stock_2330.png` 底部的「記一筆交易／持股明細」與 `19_holding_2330.png` 的「＋ 除息」是全圓膠囊；`19_holding_2330.png` 的「編輯這批」是純文字按鈕，和旁邊的外框膠囊並排。
- 危險動作沒有視覺區分：〔圖〕`16_txn_linepay_60.png` 的「刪除」與「複製」是同樣的黑框按鈕（〔碼〕`ui/screens/TxnEditor.kt:875` `color = onSurface`）；`19_holding_2330.png` 標題列的「刪除整檔持股」垃圾桶與「K 線與資訊」圖示並排，同色且沒有文字。
- 「待確認」顏色不一致：交易列表用主色珊瑚文字（〔碼〕`ui/screens/TransactionsTab.kt:707, 752`；〔圖〕`15_txns_after_notifications.png`），通知紀錄用琥珀色標籤（〔圖〕`18_notif_log.png`）。
- 設定首頁是兩欄卡片（〔圖〕`11_settings.png`），工具頁也是卡片格（`10_tools.png`），與 App 其他「線條分隔」列表的風格不同；`AppearancePrefs.cards`（線條／卡片切換，`ui/Theme.kt:198-205`）不影響這兩頁。
- 點擊波紋：全 UI 有 204 處 `.clickable`，只有 6 處設 `indication = null`；沒有任何 `LocalRippleConfiguration` 或 `LocalIndication` 的全域覆寫〔碼〕（grep 結果）。commit `61950c3` 只移除了「持股紀律」一頁的波紋。
- Compose 官方提供以 `LocalRippleConfiguration provides null` 全域停用 Material 波紋的做法〔外〕[Android Developers – Migrate to Indication and Ripple APIs](https://developer.android.com/develop/ui/compose/touch-input/user-interactions/migrate-indication-ripple)。
- 分段按鈕適合 2～5 個互斥選項；Filter chip 用於可多選的篩選〔外〕[Android – Segmented button](https://developer.android.com/develop/ui/compose/components/segmented-button)；[Android – Chip](https://developer.android.com/develop/ui/compose/components/chip)。

### Inferences（修正建議）
1. **全域停用波紋**（S）：在 `MoneyTheme` 的 `CompositionLocalProvider` 加入 `LocalRippleConfiguration provides null`，一行解決 204 處。選取狀態改用底色或文字粗細表示（SubTabs 已經是這樣做）。
2. **單選統一為 SubTabs**（M）：ReviewScreen 的「每月／每季／每年」、通知紀錄的五個篩選、StockFeeScreen、Setup、AccountScreens 的互斥 FilterChip 全部改成 SubTabs；選項超過 5 個的（通知紀錄）改成「篩選 ▾」下拉。RecurringScreens 與 InvestScreens 的 M3 SegmentedButton 也改成 SubTabs，維持一種外觀。
3. **共用元件收斂**（M）：新增 `SectionHeader(title, trailing)` 取代 49 處手刻標題；新增 `AppDivider()` 只用 `outlineVariant`；新增 `DangerTextButton`，用 `colorScheme.error`，套用到所有「刪除」。按鈕統一用 `Themes.shapes(corner)` 的圓角，不另外寫 `RoundedCornerShape(50)`。
4. **語意色 token**（S）：在 Theme 加入 `Warning`、`Pending`、`ChartPalette`（一套），7 套調色盤改為引用同一套。「待確認」一律用 `Pending` 色。
5. 記帳鍵盤面板改用 `inverseSurface`／`secondaryContainer`（S）。

### Gaps
- 沒有確認「卡片／線條」設定切換後設定頁與工具頁的實際外觀（截圖只拍預設值）。

## 三、觸控區與無障礙描述

### Takeaway
小於 48dp 的元件一個都還沒修，再加上全域 0.93 縮放，連 M3 預設的 48dp `IconButton` 也只有約 44.6dp。圖表仍然沒有任何讀屏摘要。

### Cited Findings
- 每個互動元素至少 48×48dp〔外〕[Android Developers – Make apps more accessible](https://developer.android.com/guide/topics/ui/accessibility/apps)。
- 不足 48dp 的元件（原始尺寸，還要再乘 0.93）：HelpIcon 32dp（`ui/components/HelpIcon.kt:26`）、AI 回覆的複製與重新產生 36dp（`ui/screens/AdvisorScreen.kt:1008, 1017`）、地圖縮放 36dp（`ui/screens/SpendMapScreen.kt:643`）、排序列刪除 40dp（`ui/components/Reorder.kt:119`）、帳戶幣別鈕 44dp（`ui/screens/AccountScreens.kt:194`）、SubTabs 約 34dp（`ui/components/SubTabs.kt:35`）〔碼〕。
- 〔圖〕`05_assets.png` 信用卡標題右側的「?」說明圖示，目視約 20dp。`13_editor_at_cafeteria2.png` 日期列右側的「週期/分期」文字約 10sp，字小且點擊範圍不清楚。
- `Icon(…, null)` 共 40 處沒有描述，94 處有中文描述〔碼〕。有描述的字串是否經過 `tr()` 沒有逐一確認（見 Gaps）。
- 自訂可點元件（SubTabs 的 `Box.clickable`）沒有 `role = Role.Tab`，也沒有標示選取狀態〔碼〕`ui/components/SubTabs.kt:32-35`。
- `semantics` 0 處；K 線、推估、強弱、漲跌比較、圓餅圖、日支出長條都無法被讀屏讀出〔碼〕。

### Inferences（修正建議）
1. 讓「標準」介面大小等於 1.0（拿掉 `BASE_UI_SCALE` 或改為 1f），若使用者覺得太大，可在外觀設定選「小」（S）。
2. HelpIcon、複製、重新產生、縮放、排序刪除改用 `Modifier.minimumInteractiveComponentSize()`，視覺尺寸不變（S）。
3. SubTabs 每格加 `heightIn(min = 40.dp)` 加上 `semantics { role = Role.Tab; selected = sel }`；`SubTabs` 改用一般密度，不包 `ChromeScale`（S）。
4. 每張 Canvas 圖表外層加一行文字摘要的 `Modifier.semantics { contentDescription = … }`，例如「近 120 日收盤 2340，月線 2350 下彎」（M）。

### Gaps
- 未用 Accessibility Scanner 或 TalkBack 實測；Icon 描述字串的英文翻譯覆蓋率未單獨計算。

## 四、資訊密度與漸進式揭露（個股、記帳表單、股票助理）

### Takeaway

### Cited Findings
