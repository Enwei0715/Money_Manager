## 3. 對話紀錄是否進 AI prompt？刪除後是否從 context 消失？

### Takeaway
會。每次提問從**目前對話** `st.chat.takeLast(6)` 取上下文（planTools 取 4、每則截 150 字；advisorChat 取 6、每則截 300 字）。因為每次都從 store 現讀，刪除的訊息下一次提問就不在 context 裡，**不需額外處理**。但有兩個例外要注意：(a) 執行中那一輪用的是開始時的快照；(b) 每日選股會從**所有對話（含過去的）**撈「請檢討近…」的結論。

### Cited Findings
- `askAdvisor` 開頭 `val st = ds.load()`，再把問題加進 chat（重試不重複加）— `…/data/Advisor.kt:642-645`。
- planTools 上下文 `history0 = st.chat.takeLast(6)` — `Advisor.kt:655-656`；`GroqAi.planTools` 再 `takeLast(4)`、`take(150)` — `…/net/GroqAi.kt:1091-1104`。
- advisorChat 上下文 `history = st.chat.takeLast(6)` — `Advisor.kt:718-719`；`GroqAi.advisorChat` 組成「先前對話：」`takeLast(6)`、`take(300)` — `GroqAi.kt:1047, 1067-1068`。
- 回覆寫回：`ds.update { it.copy(chat = (it.chat + fixed).takeLast(40)) }` — `Advisor.kt:803`。寫回的是「當下的目前對話」，不是發問時的那段。
- 每日報告用的「檢討結論」：`(listOf(st.chat) + st.chatThreads.map { it.msgs })` 找 `請檢討近` 問答，30 天內最新一則 — `Advisor.kt:583-586`。→ 刪掉那段對話／那則回覆會讓之後選股不再參考該檢討（應在刪除確認文案提示）。
- 背景執行：`ChatJob.ask` 用 app scope 直接跑 `askAdvisor`，離開畫面仍繼續 — `…/work/ChatWorker.kt:41-47, 58-79`；`stop()` 取消 `:50-56`，`askAdvisor` 結尾 `yield()` 讓取消不寫入 `Advisor.kt:802`。

## 4. 備份（FullBackup.kt）

### Takeaway
備份已包含 `chat` 與 `chatThreads`；還原時 `chat` 直接覆蓋、`chatThreads` 若備份為空則保留現有。新增刪除功能**不必改備份格式**。

### Cited Findings
- 匯出：`advisor = NewsStore(report, history, chat, chatThreads, business, historyKeepDays)` — `…/data/FullBackup.kt:112`。
- 還原：`chat = a.chat, chatThreads = a.chatThreads.ifEmpty { it.chatThreads }` — `FullBackup.kt:180-184`。語意：使用者刪光過去對話後還原舊備份，會把備份裡的對話帶回（合理）；備份沒有 threads 時不會清掉現有（也合理）。舊備份無 `chatThreads` 欄位 → 預設空 → 保留現有，向下相容。
- 若未來改成統一 `conversations` 模型才需要處理備份相容；本計畫不建議改。
