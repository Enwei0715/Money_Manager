# 帳理 Ledgerly（Android 記帳 App）

為台灣日常生活設計的個人記帳 App。資料只存在手機本機（Room / SQLite），可匯出 JSON 備份。

## 功能

| 功能 | 說明 |
| --- | --- |
| 通知自動記帳 | 監聽你勾選的銀行、信用卡、LINE Pay／街口／全支付、簡訊等 App 推播，自動辨識金額、幣別、商家、卡號末四碼。可設定直接入帳或先放「待確認」。多個 App 同時通知同一筆消費會自動去重。 |
| 券商成交回報 | 通知中的「成交回報：買進 2330 台積電 1張 成交價 1,050」會自動建立股票交易並估算手續費／交易稅。 |
| 信用卡自動扣繳 | 信用卡帳戶設定結帳日、繳款日、扣款帳戶後，每到繳款日自動從銀行轉帳「結帳日欠款 − 已繳金額」。首頁顯示即將到期的帳單。 |
| 週期交易 | 訂閱、房租、保費、薪水、定期定額等，支援每天／每週／每月（月底自動調整）／每年與間隔；離線多天也會補帳。 |
| 自動轉帳 | 跨行提款 → 銀行轉現金；銀行「電支交易」扣款 → 銀行轉電子錢包（例如街口自動儲值）；自己兩個帳戶一出一入、金額相同且 10 分鐘內 → 合併為轉帳。 |
| 對帳 | 街口、悠遊付等不推播消費的錢包：在帳戶明細按「對帳」輸入實際餘額，差額自動記成支出。 |
| 股票投資 | 位於「帳戶 → 股票」分頁，開啟時每 30 秒更新報價。台股（證交所即時報價，上市／上櫃）、美股（Yahoo Finance）。平均成本法計算未實現／已實現損益、股利、今日漲跌；買賣金額可連動交割帳戶餘額。 |
| 即時匯率 | 用到的幣別以 Yahoo 外匯即時報價更新，其餘用每日匯率（open.er-api.com）；多幣別帳戶與交易都換算成基準幣計算淨資產與報表。 |
| 報表 | 分類圓餅圖、近 6 個月收支趨勢、月均收支。 |
| 自動分類 | 內建台灣常見商家關鍵字；你確認過的商家分類會被記住，下次自動套用。 |
| 英文介面 | 設定 → 外觀 → 語言：跟隨系統／繁體中文／English；App 名稱同步切換（帳理／Ledgerly）。 |
| 自動除權息 | 依 Yahoo 除權息資料與除權息前一天的各批庫存，自動建立現金股利與配股紀錄（分配方式同券商除息試算）。 |
| 通知一鍵分類 | 通知記帳後的提示可直接點最常用的分類或輸入說明，不必開 App。 |
| 自動雲端備份 | 選一次備份檔位置（Google 雲端硬碟、OneDrive、Dropbox 或手機資料夾），定期覆寫完整備份（.lgbak）；另有 Android 系統的 Google 備份。 |
| 桌面小工具 | 統計（圓餅）、記一筆（1×1）、今日支出（2×1）、股票（2×1）、帳戶餘額（3×2）、最近交易＋預算（4×3）。 |
| 自動更新 | App 內「設定與更新」→ 檢查更新，直接下載並安裝 GitHub Release 上的新版 APK。 |

## 從 Money Manager 搬家

1. Money Manager：更多 → 備份 → 匯出，取得 `.mmbak` 檔。
2. 帳理：更多 → 備份 → 從 .mmbak 匯入（可選「合併」或「取代」）。
3. 會匯入帳戶（含隱藏、信用卡結帳日／繳款日與繳款帳戶）、分類與子分類、收入／支出／轉帳、餘額調整、外幣交易（以帳戶幣別金額入帳，原幣寫在說明）、備忘與週期設定；同一份檔重複匯入不會重複。
4. 也可以「匯出為 .mmbak」，以相同資料表結構備份。

## 安裝與更新

1. 每次推送程式，GitHub Actions 都會自動編譯並發布 Release（`v1.0.<build>`）。
2. 手機下載 APK 安裝（需允許「安裝不明應用程式」）。
3. 之後到 App 的 **更多 → 設定與更新** 填入 GitHub Token（因為儲存庫是私人的），按「檢查更新」即可一鍵更新。
   Token 建立方式：GitHub → Settings → Developer settings → Fine-grained tokens → 只選此儲存庫，權限 Contents: Read-only。

### 固定簽章金鑰（自動）

Android 只允許「相同簽章」的 APK 覆蓋安裝。CI 第一次建置時會自動產生一把簽章金鑰，保存在**草稿 Release「signing-key」**（只有對儲存庫有寫入權限的人看得到），之後每次建置都用同一把，所以新版可以直接覆蓋安裝、資料不會遺失。

- **請勿刪除**草稿 Release「signing-key」，否則下一版的簽章會不同，必須解除安裝才能更新。
- 如果之後要把儲存庫改成公開，請先改用 Secrets：下載草稿裡的 `signing.jks`，把 `base64 -w0 signing.jks` 的結果存成 `KEYSTORE_BASE64`、`KEYSTORE_PASSWORD` 設為 `mm-release-key`，再刪除草稿 Release。CI 會優先使用 Secrets。

## 第一次使用建議

1. **更多 → 帳戶與信用卡**：建立銀行、信用卡（填末四碼、結帳日、繳款日、扣款帳戶）、電子支付、證券交割帳戶。
2. **更多 → 通知記帳**：開啟通知存取權，勾選要監聽的 App，並為每個 App 指定記入的帳戶。可在「測試辨識」貼上一則通知確認是否辨識正確。
3. **更多 → 週期交易**：加入訂閱與固定收支。
4. **投資**：輸入目前持股（買進紀錄）。

## 專案結構

```
core/   純 Kotlin 商業邏輯（通知解析（含轉帳配對）、計算機、週期／信用卡帳單週期、股票損益），含單元測試
app/    Android App（Jetpack Compose、Room、WorkManager、NotificationListenerService）
```

本機測試核心邏輯：`./gradlew :core:test`；編譯 App 需要 Android SDK（`./gradlew :app:assembleRelease`）。

## 已知限制

- 券商帳戶無公開 API 可直接連線，持股以「成交回報通知」或手動輸入建立。
- 通知格式因銀行而異，辨識不到的格式可在「通知自動記帳 → 最近處理紀錄」查看原文，回報後加入規則。
